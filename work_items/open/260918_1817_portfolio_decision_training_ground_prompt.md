# 5. CORE OBSERVATIONS DEVELOPED SO FAR

Several ideas have emerged repeatedly.

### 5.1 Loss magnitude alone is insufficient

A $100 loss is not necessarily equivalent to another $100 loss.

Relevant dimensions may include:

* original lot allocation;
* loss in dollars;
* loss as percentage of allocation;
* age;
* volatility;
* current technical structure;
* fundamental condition;
* liquidity;
* position size;
* number of shares;
* whether the position is speculative;
* whether it is a core candidate;
* whether it can still be harvested;
* opportunity cost;
* attention cost.

The exact way these dimensions should interact remains unresolved.

---

### 5.2 A loss threshold is a REVIEW trigger, not automatically an EXIT trigger

For example, a threshold such as -$50 or -$100 may identify inventory deserving attention.

It should not automatically mean:

> loss exceeds threshold → sell.

The threshold is potentially an entry point into a decision process.

---

### 5.3 Tiny speculative positions are different

Emilio intentionally sometimes creates very small speculative positions.

A tiny position may function as a **seed**:

> start small → observe → gain evidence → potentially add → potentially promote.

If the thesis does not develop, Emilio may intentionally leave the tiny position largely unattended.

Therefore:

> tiny + negative ≠ automatically problematic.

Some tiny positions may deserve an **IGNORE** classification because their capital and attention costs are negligible.

---

### 5.4 Attention is a scarce resource

A portfolio with ~140 positions cannot give every position equal analytical attention.

Therefore the eventual system may need to decide not only:

> What should I do with this position?

but first:

> **Does this position deserve my attention?**

This is an important emerging concept.

The exact mechanism for measuring or incorporating attention cost is unresolved.

---

### 5.5 Break-even is information, not necessarily the objective

A position should not automatically be held merely because Emilio wants to recover his original money.

Break-even may instead provide information about:

* market behavior;
* resistance;
* harvesting opportunities;
* the viability of the position;
* whether the position is becoming productive again.

There is an emerging distinction between:

### Recovery Hold

Holding primarily because the position is below cost and the trader wants to recover the loss.

### Productive Hold

Holding because the position is still capable of producing useful trading/harvesting behavior and the underlying thesis has not materially deteriorated.

This distinction is useful but is not yet a fully formalized rule.

---

### 5.6 Consolidation can justify continued holding

An old losing position does not necessarily need to be closed immediately if:

* the fundamentals are not deteriorating materially;
* the stock remains technically productive;
* support/resistance behavior allows harvesting;
* the position is still serving a useful purpose.

Emilio has discussed observing such a situation for roughly **3–4 weeks**.

This is a working concept, not a universal fixed rule.

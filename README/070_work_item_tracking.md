# Work Item Tracking

Technical issues and development tasks are tracked under `Work Items/`:

- `Work Items/Open/` contains issues and tasks that still require investigation, implementation, or verification.
- `Work Items/Completed/` contains work items that have been completed and whose completion criteria have been verified.

Keep detailed issue descriptions in their work-item documents rather than duplicating them in the project overview. Move an item from `Open/` to `Completed/` only after its fix or requested work has been implemented and verified. Preserve enough detail in each item to understand the problem, expected outcome, and validation required.

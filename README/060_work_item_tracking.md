# Work Item Tracking

Technical issues and development tasks are tracked under `work_items/`:

- `work_items/open/` contains issues and tasks that still require investigation, implementation, or verification.
- `work_items/completed/` contains work items whose completion criteria have been implemented and verified.

Keep detailed issue descriptions in their work-item documents rather than duplicating them in general project documentation. Preserve enough detail to understand the problem, expected outcome, and required validation. Move an item from `Open/` to `Completed/` only after its completion criteria have been verified.
